One funny line, at most 200 characters, written to `/output/entry.txt` for the
[One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea)
bounty on make.fun.

## Entry

> I told my AI assistant to be more human — now it ghosts me, blames the Wi-Fi, and says 'per my last email'.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` after checking it is a single line of
1–200 characters.
